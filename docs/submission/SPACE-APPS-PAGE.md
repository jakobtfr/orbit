# Official Space Apps project page (global judging)

The 15:00 email is the local hand-in for Heilbronn. Global judging is a separate step: every required field on the official Project Submission page must be filled in by **23:59 tonight** (`docs/challenge/judging.md`). If a field is empty, the project is not eligible for global judging.

Who fills it in: **not known yet.** The team owner on spaceappschallenge.org must do it, or a member they add.

## Steps

1. Sign in on spaceappschallenge.org and open the team's project, under the Heilbronn local event.
2. **Members tab:** all four members must be listed: Jakob Friedrich, Lukas Fuchs, Mohit Nandanwar, Patryk Ostern. Each one must be registered for Heilbronn and not waitlisted.
3. **Challenge:** Create Health Monitoring Software for Astronauts on Space Missions.
4. Copy each field from [`../submission.md`](../submission.md). Each field there has its own heading with the same name:

| Field on the page | Heading in `submission.md` |
|---|---|
| Project Name | Project Name (ORBIT) |
| High-Level Project Summary | High-Level Project Summary |
| Link to Project Demo | Link to Project Demo: copy the URL line only |
| Link to Final Project | Link to Final Project: the live app URL; put the repository in the text if the page allows it |
| Detailed Project Description | Detailed Project Description |
| Use of Super Intelligence (SI) | Use of Super Intelligence (SI): not the grey note above it |
| NASA Data | NASA Data |
| Space Agency Partner Data / References | Space Agency Partner Data and Other References |

5. Tick the box that the work is original and that all external resources are listed.
6. Open the demo link and the live app link from the page in a private window.
7. Submit before 23:59.
